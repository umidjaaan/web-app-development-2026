# Дизайн трёх экранов в Figma

В папке `docs/figma/` лежат три файла-заготовки:

| Файл | Экран | Размер фрейма |
|---|---|---|
| `screen-1-feed.svg` | Лента | 390 × 844 |
| `screen-2-add.svg` | Добавление | 390 × 1420 |
| `screen-3-catalog.svg` | Плитка | 390 × 1660 |

Figma импортирует SVG как **редактируемые слои**: текст остаётся текстом,
прямоугольники — прямоугольниками, цвета подтягиваются автоматически.
Экраны «Добавление» и «Плитка» сделаны выше 844 px, потому что страницы
прокручиваются: так на макете видно всё содержимое, а не только первый экран.

---

## Часть 1. Собрать макет (20–30 минут)

### Шаг 1. Создать файл

1. Открыть [figma.com](https://figma.com), нажать **New design file**.
2. Переименовать файл: двойной клик по названию вверху → `РИП ЛР1 — Амфора`.

### Шаг 2. Импортировать экраны

Перетащить все три `.svg` из проводника прямо на холст Figma.
Каждый превратится в группу слоёв.

Если Figma спросит про шрифт — выбрать **Inter** (он встроенный).

### Шаг 3. Превратить группы во фреймы

Для каждой группы:

1. Выделить её на холсте.
2. **Ctrl + Alt + G** — обернуть во фрейм.
3. Переименовать на панели слоёв (двойной клик): `1. Лента`, `2. Добавление`,
   `3. Плитка`.
4. Справа в панели проверить **W** и **H** — должны совпасть с таблицей выше.

Расставить фреймы в ряд с промежутком примерно 80 px.

### Шаг 4. Завести цветовые стили

Это то, что преподаватель проверяет в первую очередь: «три точных цвета».

1. Нарисовать в стороне квадрат (**R**, затем протянуть мышью).
2. Справа в разделе **Fill** кликнуть по образцу цвета, вписать `1A1A1A`.
3. Нажать иконку из четырёх точек справа от Fill → **+** → имя `ink` → **Create style**.
4. Повторить для остальных цветов, каждый раз меняя заливку квадрата:

| Имя стиля | HEX | Назначение |
|---|---|---|
| `ink` | `1A1A1A` | графит Arzamas: текст на бежевом, полосы диаграммы |
| `paper` | `E8E8E1` | бежевый Arzamas: карточки, светлые блоки |
| `yellow` | `FECF00` | акцент: активная вкладка, кнопки, регион-лидер |
| `shell` | `111110` | фон экрана |
| `sand` | `B8B8A8` | вторичный текст на тёмном |
| `muted` | `4C4C4C` | вторичный текст на бежевом |

Квадрат после этого удалить — стили останутся в файле.

### Шаг 5. Завести текстовые стили

Кликнуть по любому заголовку на макете, справа в разделе **Text** нажать
иконку из четырёх точек → **+** → задать имя.

| Имя | Размер / интерлиньяж | Начертание | Где на макете |
|---|---|---|---|
| `brand` | 17 / 23, letter-spacing 14 %, CAPS | Bold | логотип «АМФОРА» |
| `display` | 28 / 30 | Bold | заголовок карточки в ленте |
| `title` | 26 / 29 | Bold | «Категории импорта» |
| `body` | 14 / 20 | Regular | описания, признаки-маркёры |
| `caption` | 12 / 16 | Regular | подписи полей, метаданные |
| `overline` | 11 / 14, letter-spacing 6 %, CAPS | Medium | «НАХОДОК», «ИЗОБРАЖЕНИЕ» |
| `card-title` | 14 / 17 | Bold | название на карточке плитки |
| `number` | 19 / 22 | Bold | числа статистики |

### Шаг 6. Собрать компоненты

Компонент — это переиспользуемый элемент; правка мастер-копии меняет все
экземпляры. Выделить элемент и нажать **Ctrl + Alt + K**.

Собрать пять штук:

1. **Pill** — тег региона: высота 26, радиус 999, обводка `paper` 55 %.
   Вариант `draft`: заливка `yellow`, текст `ink`.
2. **Button** — высота 46, радиус 999.
   Варианты: `primary` (`yellow`), `next` (`paper` + стрелка), `filter` (радиус 10).
3. **Field** — поле ввода: высота 44, радиус 10, обводка `paper` 22 %.
4. **Card** — карточка плитки: 175 × 322, радиус 20, фон `paper`.
5. **Tabbar** — панель навигации: 390 × 74, три равные колонки.

### Шаг 7. Показать hover

Методичка требует продемонстрировать hover. Проще всего сделать это вариантами:

1. Выделить компонент **Card** → на панели справа **Variants** → **+**.
2. У второго варианта задать `Property 1 = hover`.
3. Для hover-варианта: сдвинуть на −3 px по Y, добавить тень
   **Effects → Drop shadow**: X 0, Y 10, Blur 26, цвет чёрный 45 %.

То же самое для **Button**: у hover-варианта заливка меняется на `yellow`.

### Шаг 8. Навести порядок в слоях

Переименовать группы внутри фреймов по-человечески: `Topbar`, `Info`,
`Stats`, `RegionShares`, `Filter`, `Grid`, `Tabbar`. При импорте часть
имён уже проставлена — проверить и поправить остальные.

## Часть 2. Что говорить на защите (скриншоты 1–9)

**Скриншоты 1–7 — тема и дизайн.** Показать три фрейма в Figma рядом с теми
же экранами в браузере. Назвать вариант: история и культура, оценка торговых
связей по статистике импортных находок; услуга — категория импортных товаров
с центром производства.

**Скриншоты 8–9 — источник стилистики.** Открыть arzamas.academy рядом
с макетом и перечислить, что именно скопировано:

| Элемент | Значение | Где в макете |
|---|---|---|
| Графитовый фон | `#1A1A1A` | фон экранов, полосы диаграммы |
| Фирменный бежевый | `#E8E8E1` | карточки плитки, блок долей |
| Жёлтый акцент | `#FECF00` | активная вкладка, кнопки, регион-лидер |
| Скругление карточек | 20 px | Card, блок долей, fieldset |
| Теги-пилюли | радиус 999, паддинг 0 × 16, 14 px / 500 | Pill |
| Переход | 0.2 s | hover карточки и кнопок |
| Композиция карточки | изображение на всю ширину, тег в левом верхнем углу | Card |

Шрифт Arzamas — Formular, он проприетарный, поэтому в макете и в вёрстке
взят системный гротеск с тем же рисунком (Inter → Helvetica Neue → Arial).
Это честнее, чем ставить пиратскую копию, и об этом стоит сказать вслух.

## Часть 3. Как перерисовать заготовки

Если данные в `internal/app/repository/data.go` изменятся и макет
разойдётся с приложением, SVG можно собрать заново скриптом
`tools/genfigma/gen_svg.py`:

```bash
python3 tools/genfigma/gen_svg.py
```

Скрипт берёт изображения из `media/img/` и раскладывает экраны по тем же
координатам, что и CSS в `resources/styles/`.
